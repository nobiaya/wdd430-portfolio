# WDD 430 Portfolio

This is my personal portfolio project for the WDD 430 course, built using [Next.js](https://nextjs.org/).

## Getting Started

First, install the project dependencies:

```bash
npm install
```

Then, start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

You can start editing the page by modifying `app/page.tsx`. The page automatically updates as you make changes.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
